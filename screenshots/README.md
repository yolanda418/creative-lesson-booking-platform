# Screenshots

This directory is reserved for portfolio screenshots.

Suggested filenames:

- `landing-page.png` — Public landing page
- `ai-assistant.png` — AI Course Assistant in action
- `mini-program.png` — WeChat Mini Program (authorized student view)

Binary image files in this folder are gitignored. Add screenshots manually
when preparing a release.

本目录保留给作品集截图使用。
图片文件本身已被 .gitignore 忽略，正式发布时再手动加入。

# 上线操作指南(零成本方案 · 个人主体发布版)

> 适用规模:1 位老师 + 3~5 位老师 + 30 位学生家长(50 人以内),全部免费。
> 主体:**个人**(无营业执照场景下唯一选项)。
> 发布方式:完成**小程序备案**(¥0)+ 提交**发布审核**(¥0)。

按下面顺序做,大约 30~60 分钟跑通代码 + 1~2 周走完备案+发布审核。每一步我都标了 ⏱️ 预计耗时 和 💸 花费(都是 💸0)。

> 💡 **没拿到备案号之前**,你仍然可以:
> - 在微信开发者工具里调试所有功能
> - 上传代码、扫码体验(限 50 个体验成员)
> - 跟朋友/家长试用
>
> 这些都不需要备案。备案只是"全网发布"的硬门槛。

---

## 第一阶段:账号注册(15~30 分钟,主要是等审核)

### Step 1: 注册小程序账号 ⏱️ 5 分钟(注册)+ 1~24 小时(审核)💸0

- 浏览器打开 https://mp.weixin.qq.com
- 用你**个人的**微信号扫码登录(已登录的话不用再登)
- 顶部「立即注册」→「小程序」
- 邮箱用一个**没注册过微信公众平台的**(QQ 邮箱、163 邮箱都行)
- 按提示填完基本信息和身份证,主体选「个人」
- 提交后等审核(几分钟到几小时,过了会短信通知你)

### Step 2: 拿到 AppID ⏱️ 1 分钟 💸0

- 审核通过后,左侧菜单「开发管理」→「开发设置」
- 滚到「开发者ID」一节,有个 **AppID(小程序ID)** —— 一串 `wx` 开头的字符
- **复制下来,只发 AppID 给帮你写代码的人,千万别发 AppSecret**

---

## 第二阶段:填代码 + 装环境(20~30 分钟)

### Step 3: 打开微信开发者工具,导入项目 ⏱️ 2 分钟 💸0

- 打开微信开发者工具(你已下载,登录了)
- 左上角「小程序」→「+」(导入项目)
- 项目目录: `D:\violin-app\violin-app`
- AppID: 粘贴 Step 2 拿到的 AppID
- 后端服务: 选「微信云开发」
- 点击「确定」

⚠️ 此时打开会报错("云开发环境 ID 没填"),正常,继续往下做。

### Step 4: 开通云开发 ⏱️ 2 分钟 💸0

- 微信开发者工具顶部菜单「云开发」→「开通」
- 用创建小程序的那个微信扫码确认
- 「新建环境」: 起个名字(比如 `violin-prod`),付费套餐选**「免费版」**(够你用了)
- 创建完,你会看到一个「环境 ID」,**复制下来**

### Step 5: 把云环境 ID 填到代码里 ⏱️ 1 分钟 💸0

- 用编辑器打开 `D:\violin-app\violin-app\miniprogram\app.js`
- 第 17 行 `env: 'your-cloud-env-id'` → 改成 `env: '你刚复制的环境ID'`

### Step 6: 申请订阅消息模板 ⏱️ 3 分钟 💸0

(这一步也可以跳过先,只影响提醒功能,不影响预约/查看课程这些核心功能)

- mp.weixin.qq.com 左侧菜单「订阅消息」→「公共模板库」
- 搜索 "课程提醒",挑一个字段包含「课程名称」和「上课时间」的,点「选用」
- 再搜"下课提醒",同样操作
- 回到「我的模板」,你会看到两个模板 ID,各点一下「详情」复制那个 ID

把这两个 ID 填到 3 个文件的固定位置(我已经在文件里加了 ⏳ 占位符,搜 `你的-上课提醒-模板ID` 一找就找到):

- `cloudfunctions/sendReminders/index.js`
- `miniprogram/pages/student/detail/detail.js`
- `miniprogram/pages/teacher/students/students.js`

⚠️ **三个文件的"上课提醒"必须是同一个值,"下课提醒"也是**,不一致会导致只有部分人收到提醒。

### Step 7: 验证配置 ⏱️ 30 秒 💸0

打开 PowerShell(就在你的项目目录里),跑:

```
node scripts/check-config.js
```

全部 ✅ 就可以继续。如果还有 ⏳,按提示回头补。

### Step 8: 创建数据库集合 ⏱️ 5 分钟 💸0

- 微信开发者工具顶部「云开发」→「数据库」
- 点「+ 添加集合」,依次创建以下 6 个,名字**完全一致**:
  - `subjects`
  - `teachers`
  - `students`
  - `lessons`
  - `subscriptions`
  - `cancellations`

### Step 9: 插入种子数据 ⏱️ 2 分钟 💸0

- 点开 `subjects` 集合 → 「添加记录」→ 填:
  ```
  name: 小提琴
  icon: 🎻
  ```
  保存。

### Step 10: 部署 13 个云函数 ⏱️ 10 分钟 💸0

对 `D:\violin-app\violin-app\cloudfunctions\` 下每个子文件夹:

- 在微信开发者工具左侧「云开发」→「云函数」标签
- 右键该文件夹 → 「在终端中打开」 → 跑 `npm install`
- 等装完 wx-server-sdk 后,右键该文件夹 → 「上传并部署:云端安装依赖(不上传 node_modules)」
- 看到「上传成功」就下一个

13 个文件夹依次操作:
```
adjustLesson, bookLesson, cancelLesson, createLessonSlot,
getAvailableLessons, getMyLessons, getTodayStudents, getRecentCancellations,
listStudents, login, sendReminders, subscribeReminder, updateProfile
```

`sendReminders` 部署完后,点开它 → 「触发器」标签 → 应该自动出现一个 cron = `0 */5 * * * * *`(每 5 分钟),没有的话手动加一条。

## 第三阶段:真机测试 + 试运行(1 小时,不需要备案)

> 这一步**不要求备案完成**。你可以一边开发一边让朋友扫码试用,只限 50 个体验成员。

### Step 11: 老师录入身份 ⏱️ 1 分钟 💸0

- 微信开发者工具顶部「预览」→ 扫码 → 用**老师本人的微信**扫
- 此时会自动建一条"空学生"记录(因为 `teachers` 集合里没你),正常
- mp.weixin.qq.com → 云开发控制台 → 数据库 → `students` 集合 → 找到刚才那条空记录 → 复制 `openid` 字段
- 到 `teachers` 集合 → 添加记录:
  ```
  openid: (你刚复制的)
  name: 老师姓名(比如"张老师")
  subjectIds: []
  status: active
  ```
- **关掉小程序重新打开**,这次会自动识别成老师身份
- 进入「我的课程」,点右下角「+ 新建可预约时段」,选个时间创建

### Step 12: 学生预约 ⏱️ 2 分钟 💸0

- 微信开发者工具顶部「预览」→ 用你朋友/家人的微信扫码
- 会弹出"首次使用,请填写姓名"的页面 → 填一下
- 进「预约课程」,会看到刚才老师建的时段
- 点「立即预约」→「确认」
- 进「我的课程」应该能看到刚预约的课

🎉 如果上面都成功了,核心业务流程就跑通了!

### Step 13(可选):测试提醒 ⏱️ 等 5~15 分钟 💸0

- 进任意一节课的详情页 → 点「🔔 开启这节课的提醒」→ 允许
- 等到提醒触发时间附近(上课前 15 分钟 / 下课后 5 分钟内)
- `sendReminders` 云函数每 5 分钟跑一次,扫到符合条件的课程就会推送订阅消息

### Step 14: 让 50 个好友/家长扫码使用 ⏱️ 10 分钟 💸0

> 在拿到备案号之前的这段"等待期",可以这么做:

- mp.weixin.qq.com → 左侧「成员管理」→「体验成员」
- 把 50 个微信加进去(注意是"微信号"不是"昵称",对方需要告诉你他的微信号)
- 微信开发者工具 → 顶部「上传」→ 填版本号 `1.0.0` → 上传
- mp.weixin.qq.com → 「版本管理」→ 找到刚上传的版本 → 「设为体验版」
- 截图/保存「体验版二维码」→ 发到家长群 / 好友群
- 他们扫码就能用,有效期 24 小时,过期重新生成

## 第四阶段:个人备案 + 全网发布(1~2 周,全部免费)

### ⚠️ 个人 vs 企业 备案怎么选?

| | 个人备案 | 企业备案 |
|---|---|---|
| 谁能选 | 任何个人 | 必须有营业执照 |
| 费用 | ¥0 | ¥0 |
| 审核时间 | 1~7 天 | 1~7 天 |
| 能用微信支付/收款? | ❌ 不能 | ✅ 能 |
| 小程序名字 | 不能含"公司""企业" | 可以 |

**结论:你这个场景(没有营业执照 + 不打算在线收款) → 选「个人备案」**。

### Step 15: 开始备案 ⏱️ 10 分钟填表 + 1~7 天审核 💸0

1. mp.weixin.qq.com 首页 → 「备案与认证」→「小程序备案」→「补充」
2. **主体信息**(个人):
   - 主办人 = 你的真实姓名
   - 身份证号
   - 通信地址(你的真实居住地址,虽然不会寄东西)
   - 手机号、应急电话(家人或同事)
3. **小程序信息**:
   - 名称: 琴小助(你已填)
   - 简介: **"琴小助是一款面向音乐教育场景的智能课程管理工具,支持课程预约、排课、调课、取消等,让老师和学生都能清晰掌握课程安排。"**
   - 服务类目: **教育 → 音乐教育**
   - 标签: 音乐、教育、小提琴
4. **平台验证**: 微信扫码 → 人脸识别 → 录一段 4 位数字语音(10 秒,反诈验证)
5. 提交后,工信部(不是微信)会**发短信问你"是否本人在申请备案"** → 回复"是"
6. 等 1~7 天,会收到"备案成功"短信,mp.weixin.qq.com 首页会有"备案号"

### Step 16: 提交发布审核 ⏱️ 5 分钟 + 1~3 天审核 💸0

- 微信开发者工具 → 顶部「上传」→ 填版本号(比如 `1.0.0`)和项目备注
- mp.weixin.qq.com → 「版本管理」→ 找到刚上传的版本 → 「提交审核」
- 微信会审核你的小程序内容(主要看:有没有违规内容、UI 是否完整、是否有测试数据)
- 通过后 → 「发布」→ 全网可见,可以微信搜索"琴小助"找到

### Step 17: 发布后让所有家长都能搜到 🎉

- 家长打开微信 → 顶部搜索"琴小助" → 找到你的小程序 → 直接用
- 不需要加体验成员、不限人数
- 体验成员那 50 人的限制自动解除

## ❓ 常见问题

**Q: 我朋友扫码后看到"白屏" / 一直"加载中"?**
A: 八成是某个云函数没部署成功。看微信开发者工具「云开发」→「云函数」,看哪个函数状态是"部署失败"。`login` 没部署成功最常见,因为它是启动时第一个被调的。

**Q: 学生预约后老师那边没看到?**
A: 检查 `teachers` 集合里老师的 openid 是否跟老师本人微信一致;再检查 `lessons` 集合里这条课的 `teacherId` 字段是不是这个老师。

**Q: 提醒一直收不到?**
A: 三步排查:
1. `node scripts/check-config.js` 确认三个文件的模板 ID 都填了且一致
2. 微信开发者工具 → 云开发 → 云函数 → sendReminders → 日志,看有没有报错
3. mp.weixin.qq.com → 订阅消息 → 我的模板 → 看那个模板还在不在(下架了也会失效)

**Q: 个人主体能用多久?能收多少用户?**
A: 个人主体**没有用户数量上限**,微信云开发免费额度(每天数据库读 5 万次/写 3 万次、云函数 4 万次调用、4GB 流量)对你的规模绰绰有余。

## 📱 Step 11(50 人场景必看):让 50 个好友/家长都能扫码使用

> 这一步解决你"3-5 个老师 + 20-30 个家长,总共 50 人以内"的真实场景。
> 关键点:**不需要发布、不需要备案、不需要微信认证**。

### ⚠️ 微信开发者工具的"预览码"30 分钟就过期,50 个人不能挨个扫

正确做法是:把 50 个微信加到你的「**体验成员**」里,然后给他们发「**体验版二维码**」。

### 11.1 加体验成员 ⏱️ 5~10 分钟 💸0

- 浏览器打开 https://mp.weixin.qq.com
- 左侧菜单「成员管理」→「体验成员」
- 点击「添加」按钮,输入家长/老师的**微信号**(注意是"微信号"不是"微信昵称",需要对方告诉你)
- ⚠️ **对方必须先用自己微信扫一下"确认邀请"的二维码**才会生效
- 一次最多加 50 个;50 人以内一天能加完

### 11.2 生成体验版二维码 ⏱️ 1 分钟 💸0

- 微信开发者工具 → 顶部右上角「上传」按钮 → 填版本号(比如 `1.0.0`)和项目备注 → 上传
- mp.weixin.qq.com → 「版本管理」→ 找到刚上传的版本 → 「设为体验版」
- 同一个页面会显示一个「**体验版二维码**」(有效期一般 24 小时,过期可以再生成)
- **截图或保存这个二维码**,发到家长群 / 好友群里,他们扫一下就能用

### 11.3 如果超过 50 人怎么办?

- 「体验成员」上限 **50 人/小程序**(就是你这个规模设计的)
- 超出 50 人有两条路:
  - **仍 0 成本**:做「小程序备案」(免费、1~7 天审核) → 然后「发布上线」 → 不限人数
  - **付费方案**:企业主体年审 ¥300(现在不用考虑)

### ⚠️ 假如未来你要「发布」让全网搜到你的小程序:

- **必须做**:小程序备案(¥0,1~7 天审核) — 微信官方要求的
